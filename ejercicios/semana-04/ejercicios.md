# Ejercicios — Semana 4: NFTs y Proyecto Final

## Ejercicio 1: Crear tu Primer NFT 🎨

### Instrucciones

1. Instala el SDK de Metaplex:
```bash
npm install @metaplex-foundation/umi-bundle-defaults \
  @metaplex-foundation/mpl-token-metadata
```

2. Prepara una imagen (puede ser cualquier imagen PNG) y sube los metadatos. Puedes usar [NFT.Storage](https://nft.storage/) o [Pinata](https://www.pinata.cloud/) para subir a IPFS.

3. Crea el NFT usando el código del Módulo 05 como referencia.

**Entregable**: Mint address del NFT creado en devnet.

## Ejercicio 2: Colección de NFTs 🖼️

Crea una pequeña colección de 3 NFTs con:
- Nombre coherente (ej: "Solana Academy #001")
- Metadatos únicos para cada uno
- Atributos/traits diferentes
- Todos perteneciendo a la misma colección

**Entregable**: Mint addresses de los 3 NFTs.

## Ejercicio 3: Proyecto Final Integrador 🚀

### Descripción
Crea una aplicación que combine lo aprendido en el curso:

**Opción A — Token + NFT Dashboard**
- Crea un token propio
- Acuña algunos NFTs
- Construye un script que muestre el balance de tokens y NFTs de una wallet

**Opción B — Programa Anchor con Frontend**
- Despliega un programa Anchor (el contador o almacén de mensajes)
- Crea una interfaz web simple con `@solana/wallet-adapter` que permita interactuar con el programa

**Opción C — Propuesta Propia**
- Propón tu propio proyecto que use al menos 2 conceptos del curso
- Requiere aprobación previa

### Entregables del Proyecto Final
- [ ] Código fuente en una carpeta `proyecto-final/`
- [ ] README.md explicando el proyecto
- [ ] Instrucciones de instalación y uso
- [ ] Demostración funcionando en devnet
